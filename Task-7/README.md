## 📌 Project Overview  
This project uses the **Walmart Sales Forecasting (Kaggle)** dataset to perform:  
- Exploratory Data Analysis (EDA) with respect to **time**  
- Building a **time series forecasting model** using **XGBoost**  

The goal is to identify sales patterns and forecast future sales.  

---

## 🔍 Key Highlights  
- ✅ Performed **time-based analysis** (trends, seasonality, holidays)  
- ✅ Built a **forecasting pipeline** with XGBoost  
- ✅ Achieved stable predictions with hyperparameter tuning
