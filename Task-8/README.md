## 📌 Project Overview  
This project uses the **Superstore Sales Dataset (Kaggle)** to design an **interactive Power BI dashboard**.  
The dashboard provides **sales insights across customers, products, regions, and time**, enabling data-driven business decisions.  

---

## 🔍 Dashboard Highlights  
The **6-page Power BI report** covers:  

- 👥 **Customer Analysis** – top customers, loyalty trends, segmentation  
- 💰 **Sales & Profit Analysis** – performance by category, sub-category, and region  
- 🕒 **Time Analysis** – year-over-year sales, seasonality, growth patterns  
- 🚚 **Order Analysis** – shipping performance, delivery KPIs  
- 🌍 **Geographic Insights** – sales distribution across regions  
- 📊 **KPI Summary Page** – high-level business performance indicators
